# Euphoria updates

Update feed for the Euphoria Launcher.

- **`catalog.json`** — the list of game versions the launcher shows. Edit it here (pencil icon on GitHub) to add versions, change download links or publish a game update (raise `version`). Players see changes within a few minutes.
- **Releases** — each launcher version is a release with `latest.yml`, the installer `.exe` and its `.blockmap`. Installed launchers update themselves from the newest release.
